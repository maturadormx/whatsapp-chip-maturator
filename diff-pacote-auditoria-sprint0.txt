O QUE CADA ARQUIVO FAZ

## `auditoria.py`

Implementa a classe:

- `AuditorSprint0`

Fluxo:

- recebe `log_content`
- recebe `app_logs`
- audita os 10 critérios
- gera relatório textual
- emite veredito `GO`, `NO-GO` ou `WARN`

Critérios implementados:

1. Redis PONG
2. App sem erros
3. Scheduler publica
4. Worker consome
5. Pipeline conclui
6. Métricas BEFORE/AFTER sem erro
7. 20 métricas presentes
8. Métricas aumentam
9. `npm test` verde
10. `npm run build` verde

## `scripts/coleta-evidencias.ps1`

Script PowerShell para:

- rodar `redis-cli ping`
- coletar `METRICS BEFORE`
- anexar logs da aplicação
- rodar `npm test`
- rodar `npm run build`
- coletar `METRICS AFTER`
- salvar tudo em `sprint0-evidencias.log`

## `scripts/coleta-evidencias.sh`

Versão Bash do mesmo fluxo de coleta.
