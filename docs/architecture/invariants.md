# Invariantes Arquiteturais

- O domínio depende apenas de contratos.
- Toda decisão é explícita.
- Todo efeito observável é intencional.
- Todo estado mutável possui transições explícitas.
- Todo contrato preserva compatibilidade.

> Um invariante responde: "o sistema deixa de ser esta arquitetura se isso deixar de ser verdadeiro?"
