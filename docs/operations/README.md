# Operações (baseline 2.0)

Estes documentos descrevem **como o time trabalha** (execução e governança operacional). Eles não são princípios permanentes da arquitetura.

Eles podem evoluir conforme o time amadurece, sem necessidade de ADR, desde que não alterem `Manifesto`, `Invariants` ou `Principles`.

## Documentos

- `parallelism-strategy.md`: frentes paralelas e congelamento do núcleo
- `integration-milestone.md`: marco obrigatório entre incrementos
- `adr-policy.md`: política de ADR (nunca apagar; apenas substituir)
- `merge-policy.md`: regras de merge e qualidade mínima
