# Integration Milestone (IM)

`IM` é o marco obrigatório entre incrementos. Nenhuma frente avança sem fechar um `IM`.

## Critérios mínimos

- testes unitários passando
- adapter de teste criado (quando aplicável)
- integração com núcleo validada
- suíte completa passando: `pnpm test`
- build limpo: `pnpm build`
- documentação mínima:
  - ADR se alterar contrato ou princípio
  - atualização de checklist se não for ADR
