# Política de ADR

ADRs nunca são apagados. Apenas substituídos (mudando status) quando uma decisão deixa de ser vigente.

## Status formais

| Status | Significado |
|---|---|
| `Proposed` | em discussão |
| `Accepted` | vigente |
| `Superseded` | substituído por ADR mais recente |
| `Deprecated` | obsoleto, não mais aplicável |
