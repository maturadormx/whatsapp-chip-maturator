O QUE MUDOU NA PRÁTICA

Antes:
- endpoint HTTP validava DTO e retornava `accepted` com `correlationId`/UUID

Depois:
- endpoint HTTP continua retornando `202 accepted`
- mas agora o “aceite” passa por:
  - `ObservationFactory` (DTO → Observation)
  - `ObservationPipelinePort.process(observation)`
  - `ObservationPipeline` (gera Fact internamente)

Importante:
- o HTTP não retorna `Fact`
- o `Fact` não é exposto na API externa
- o pipeline interno é o lugar onde a evolução continua

SEMÂNTICA E DISCIPLINA

- `Observation` e `Fact` são entidades puras de domínio (interfaces)
- `ObservationFactory` é transformação de inbound (DTO) para domínio (Observation)
- `FactFactory` é transformação de domínio (Observation → Fact)
- `ObservationPipeline` é camada de aplicação
- sem persistência (sem Event Store) nesta rodada
- sem orquestração do `ExecutionService` nesta rodada
